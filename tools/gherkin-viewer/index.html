See where every bounded context stands.

Pick the root folder of an hGATE project. Only docs/ and the skills folder are read, and everything stays in this browser.

First, in the project root

  1. npm run project:sync Regenerates docs/hgate-project.json.
  2. npm run project:status Writes .hgate/status.json for timelines and change summaries.

Then load the folder. Board shows lifecycle and gates, Project the BC map, Scenarios the BDD scenarios. The ? button in the top bar opens the guide.
